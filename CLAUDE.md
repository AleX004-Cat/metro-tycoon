# Правила разработки Metro Tycoon

## Режим работы с Git и GitHub
* НИКОГДА автоматически не создавай коммиты и не делай git push в репозиторий без прямого текстового подтверждения от пользователя в текущем чате.
* После написания или изменения кода ВСЕГДА сначала выводи подробный Changelog (журнал изменений) в чат.
* Жди, пока пользователь напишет "Да", "Пуш" или одобрит изменения через интерфейс, и только после этого отправляй код на GitHub.
